Icraft Demo: 自定义硬算子#

在Icraft中， 满足如下情况时：1）如果一个算子无法映射到Icraft中算子，此时用户可以通过解析组件的自定义接口将算子解析到自定义算子上， 该自定义算子放到BuyiBackend上加速；2）如果用户打算自行用BuyiBackend加速Icraft算子，可以采用自定义硬算子的方式来支持算子。

该Demo展示了如何使用自定义硬算子流程来加速Pytorch框架中的特定条件的Add算子。

Add定义如下：

1def Add(x, y):
2    return z = x + y

采用 Eltwise 算子来针对 两个相同尺寸的tensor相加/减的运算 进行加速，Eltwise的定义如下：

1def Eltwise(x, y, a, b, mode):
2    if mode=="sub":
3        return z = a*x - b * y
4    else:
5        return z = a*x + b * y

参数：

  • a (double) : 加/减数的系数.

  • b (double) : 被加/减数的系数.

  • mode (string) : Eltwise的计算模式.

二 适配流程#

Icraft支持Add算子，但是我们希望针对add算子的前向进行优化，因此我们需要自定义一个算子 Eltwise，将其注册到XIR中去，并将网络中的 Add 算子替换为 Eltwise。

2.1 注册算子#

2.1.1 算子定义#

该Demo在 samples/customop/hardop/op/eltwise.h 中完成了算子的定义和注册，该算子的命名空间为 whatever ，类名为 Eltwise ，其生成的动态链接库的名字为 whatever.Eltwise （Windows上文件名为 whatever.Eltwise.dll , Linux上文件名为 libwhatever.Eltwise.so ） 。

备注

用户可以根据需要对自定义算子的命名空间和类型随意取名，但是需要保证算子编译的动态链接库的名称为 {命名空间}.{类型名}。

根据前文框架上 Eltwise 算子的定义，我们给该算子定义了三个属性，分别为 op_mode(EltwiseMode) 、 a(double)、 b(float). 该算子的具体定义和注册过程如下所示：

2.2.2 组件接口#

算子定义完成后，还需要为算子实现前向等组件的接口，包括：

  • 量化接口 ：用于量化 ``Eltwise``算子。

  • 排布接口 ：提供算子输出tensor的排布描述。当算子的输出作为Icraft BuyiBackend算子输入时，要求自定义算子的输出满足布衣架构的排布；当算子的输出作为Icraft HostBackend算子输入时，满足原框架的排布。

  • 前向接口 ：提供算子在浮点、定点、排布、指令阶段的前向运算。

  • 布衣架构排布说明

该Demo在 samples/customop/hardop/op/eltwise.cpp 中完成了排布接口的实现，具体如下：

 1    NormalizedQuantizedType makeFtmpQuantizeTypeByChannelDistr(const NormalizedQuantizedType& quant_type,
 2            const MergedAxisDistr& chan_distrs);
 3    ICRAFT_IMPL_FUNCTOR(BYLayout) < Eltwise > ([](auto& op, auto& logger) {
 4            Array<Operation> ops;
 5            auto target = op->compile_target;
 6            if (target.is<HostTarget>()) {
 7                    ops.push_back(op);
 8                    return ops;
 9            }
10
11            //eltwise算子中ofm的layout、shape继承于ifm的layout、shape，该算子对于layout没有要求
12            auto eltwise_n = op.clone().setId(-1).cast<Eltwise>();
13            eltwise_n[0].setId(-1);
14            auto ofm = eltwise_n->outputs[0];
15            auto ofm_dtype = ofm.tensorType();
16            auto ofm_element_dtype = ofm_dtype->element_dtype;
17            auto ofm_quant_type = ofm_element_dtype.cast<NormalizedQuantizedType>();
18            auto ifm0_dtype = eltwise_n->inputs[0].tensorType();
19            auto ifm1_dtype = eltwise_n->inputs[1].tensorType();
20
21            if (ifm0_dtype->layout != ifm1_dtype->layout || ifm0_dtype->shape != ifm1_dtype->shape) {
22                    ICRAFT_LOG(EXCEPT) << "the inputs of eltwise must own the same shape and layout";
23            }
24            //获取ochan_distr, ochan_distr = ichan_distr.clone();
25            auto ct_index = ifm0_dtype->layout.getIndexOf('C');
26            auto cu_index = ifm0_dtype->layout.getIndexOf('c');
27            auto ichan_distr = ifm0_dtype.getMergedDistr({ ct_index,cu_index }).value();
28            auto ochan_distr = ichan_distr.clone();
29            //获取ofm_shape, ofm_shape = ofm_shape.clone();
30            auto ofm_shape = ifm0_dtype->shape.clone();
31            //获取ofm_layout, ofm_layout = ifm_layout.clone();
32            auto ofm_layout = ifm0_dtype->layout.clone();
33            //获取ofm_quant_type_n， 根据ofm_quant_type和ochan_distr来获取新的数据，主要完成的是补充通道参数的操作
34            auto ofm_quant_type_n = makeFtmpQuantizeTypeByChannelDistr(ofm_quant_type, ochan_distr);
35            ofm_dtype.setShape(ofm_shape).setLayout(ofm_layout).setElementDtype(ofm_quant_type_n).setMergedDistrs({ ochan_distr});
36
37            ops.push_back(eltwise_n);
38            return ops;
39            });

41    NormalizedQuantizedType makeFtmpQuantizeTypeByChannelDistr(const NormalizedQuantizedType& quant_type,
42            const MergedAxisDistr& chan_distrs) {
43            auto norm = quant_type->normratio;
44            auto scale = quant_type->scale;
45            auto storage_type = quant_type->storage_dtype;
46
47            Array<double> norm_n;
48            ExpQuantizedScaleArray scale_n;
49            int index = 0;
50
51            for (auto&& [s, e, v] : chan_distrs.allSections()) {
52                    auto num = e - s;
53                    if (v) {
54                            if (index + num > norm.size() ||
55                                    index > norm.size()) {
56                                    ICRAFT_LOG(EXCEPT) << " channel size do not match normratio size!";
57                            }
58                            norm_n.insert(norm_n.end(), norm.begin() + index, norm.begin() + index + num);
59                            scale_n = ExpQuantizedScaleArray(scale_n, scale.split(index, index + num));
60                            index += num;
61                    }
62                    else {
63                            std::vector<double> norm(num, 1.f);
64                            norm_n.insert(norm_n.end(), norm.begin(), norm.end());
65                            auto a = scale[0];
66                            ExpQuantizedScaleArray scale(num, a);
67                            scale_n = ExpQuantizedScaleArray(scale_n, scale);
68                    }
69            }
70            return  NormalizedQuantizedType(norm_n, scale_n, storage_type);
71    }
2.2.2.3 前向接口#

当前Demo中的 Add 算子是在优化组件中被替换为 Eltwise 的，因此``Eltwise`` 算子需要提供hostbackend和buyibackend前向，其中hostbackend应该支持浮点、定点、排布、指令阶段前向运算。该Demo在 samples/customop/hardop/op/eltwise.cpp 中完成了前向接口的实现，具体如下：

  1    // HostBackend中定义了各个算子在CPU/GPU上前向的过程
  2    // 下面向HostBackend中注册Eltwise算子的前向过程
  3    // 一个算子的前向实现包含init和forward两个接口，分别用于初始化以及前向过程
  4    ICRAFT_ADD_OP_TO_BACKEND(Eltwise, HostBackend)
  5            // 初始化过程的实现
  6            // 该算子不需要初始化什么，因此该函数为空
  7            .set_init([](const Eltwise& op, HostBackend backend) {})
  8            // 前向实现，根据Softplus的计算公式实现计算过程
  9            .set_forward([](const Eltwise& op, const std::vector<Tensor>& inputs, HostBackend backend) -> std::vector<Tensor> {
 10            auto& x = inputs[0];
 11            auto& x_type = x.dtype();
 12            auto& y = inputs[1];
 13            auto& y_type = y.dtype();
 14
 15            if (x_type->element_dtype.is<icraft::xir::FloatType>()) {
 16                    auto a = op->a;
 17                    auto b = op->a;
 18
 19                    auto output_tensor = icraft::xrt::Tensor(x.dtype());
 20                    output_tensor.mallocOn(x.memRegion());
 21
 22                    auto x_data = (float*)x.data().cptr();
 23                    auto y_data = (float*)y.data().cptr();
 24                    auto z_data = (float*)output_tensor.data().cptr();
 25                    for (int i = 0; i < x.dtype().numElements(); i++) {
 26                            auto z_ = a * x_data[i] + b * y_data[i];
 27                            z_data[i] = z_;
 28                    }
 29                    return { output_tensor };
 30            }
 31            else {
 32                            //z = (ax + by)+ 2^7 / 2^8
 33                            //a,b : int16, x,y:int8, z:int8
 34                            auto a = (int16_t)op->a;
 35                            auto b = (int16_t)op->a;
 36
 37                            //check x,y is int8
 38                            ICRAFT_CHECK(x_type->element_dtype.is<icraft::xir::NormalizedQuantizedType>())
 39                                    .append("Error in eltwise forward, input0 dtype is {}, integer type is expected.", x_type->element_dtype->typeKey());
 40                            ICRAFT_CHECK(x_type->element_dtype.cast<icraft::xir::NormalizedQuantizedType>().getStorageType() == icraft::xir::IntegerType::SInt8())
 41                                    .append("Error in eltwise forward, input0 dtype is {}, int8 type is expected.", x_type->element_dtype.cast<icraft::xir::IntegerType>()->typeKey());
 42                            ICRAFT_CHECK(y_type->element_dtype.is<icraft::xir::NormalizedQuantizedType>())
 43                                    .append("Error in eltwise forward, input1 dtype is {}, integer type is expected.", y_type->element_dtype->typeKey());
 44                            ICRAFT_CHECK(y_type->element_dtype.cast<icraft::xir::NormalizedQuantizedType>().getStorageType() == icraft::xir::IntegerType::SInt8())
 45                                    .append("Error in eltwise forward, input1 dtype is {}, int8 type is expected.", y_type->element_dtype.cast<icraft::xir::IntegerType>()->typeKey());
 46                            //check x_elenum == y_elenum
 47                            ICRAFT_CHECK(x_type.numElements()==y_type.numElements()).append("Error in eltwise forward, input0 size {} != input1 size {}.", x_type.numElements(), y_type.numElements());
 48
 49                            auto output_tensor = icraft::xrt::Tensor(x.dtype());
 50                            output_tensor.mallocOn(x.memRegion());
 51
 52                            auto x_data = (int8_t*)x.data().cptr();
 53                            auto y_data = (int8_t*)y.data().cptr();
 54                            auto z_data = (int8_t*)output_tensor.data().cptr();
 55                            for (int i = 0; i < x.dtype().numElements(); i++) {
 56                                    auto z_ = (int)a * (int)x_data[i] + (int)b * (int)y_data[i];
 57                                    z_ = (z_ + pow(2, 7)) / pow(2, 8);
 58                                    z_data[i] = (int8_t)z_;
 59                            }
 60                            return { output_tensor };
 61                    }
 62            });
 63
 64    /* add init&forward funcs */
 65    auto eltwise_init_buyibackend = [](const Eltwise& op, BuyiBackend backend) {
 66
 67            auto device = backend->device;
 68            uint64_t reg_base = 0x100001800;
 69            //检查硬件的版本信息是否正确，不正确会抛出错误
 70            if (device.defaultRegRegion().read(reg_base + 0x008, true) != 0x23120600) {
 71                    throw std::runtime_error("ERROR :: No Eltwise HardWare");
 72            }
 73    };
 74
 75    auto eltwise_forward_buyibackend = [](const Eltwise op, const std::vector<Tensor>& inputs, BuyiBackend backend) {
 76            std::chrono::milliseconds timeout_duration(10000);
 77            for (auto& input : inputs) {
 78                    input.waitForReady(timeout_duration);
 79            }
 80
 81            //仅支持8bit模式
 82            auto ofm_dtype = op[0].tensorType();
 83            auto ifm_shape = inputs[0].dtype()->shape;
 84            auto ifm_size = std::accumulate(ifm_shape.begin(), ifm_shape.end(), 1, std::multiplies());
 85            auto device = backend->device;
 86            uint64_t reg_base = 0x100001800;
 87
 88            auto arbase0 = backend->forward_info->value_map.at(op->inputs[0]->v_id)->phy_addr;
 89            auto arbase1 = backend->forward_info->value_map.at(op->inputs[1]->v_id)->phy_addr;
 90            auto awbase = backend->forward_info->value_map.at(op->outputs[0]->v_id)->phy_addr;
 91
 92            //寄存器配置
 93            device.defaultRegRegion().write(reg_base + 0x014, 1, true); //软复位
 94            device.defaultRegRegion().write(reg_base + 0x014, 0, true);
 95            device.defaultRegRegion().write(reg_base + 0x01C, arbase0, true);  //第一张输入ftmp的基地址，byte地址
 96            device.defaultRegRegion().write(reg_base + 0x020, arbase1, true);  //第二张输入ftmp的基地址，byte地址
 97            device.defaultRegRegion().write(reg_base + 0x024, std::ceil((float)(arbase0+ ifm_size)/ 64 ) * 64, true); //第一张输入ftmp ceil((base + size)/64)*64 - 64
 98            device.defaultRegRegion().write(reg_base + 0x028, std::ceil((float)(arbase1 + ifm_size) / 64) * 64, true); //第二张输入ftmp ceil((base + size)/64)*64 - 64
 99            device.defaultRegRegion().write(reg_base + 0x02C, awbase, true);  //输出ftmp基地址
100            device.defaultRegRegion().write(reg_base + 0x030, std::ceil((float)(awbase + ifm_size) / 64) * 64, true); //输出ceil((base + size)/64)*64 - 64
101            device.defaultRegRegion().write(reg_base + 0x034, op->a, true);  //参数a的值
102            device.defaultRegRegion().write(reg_base + 0x038, op->b, true);  //参数b的值
103            device.defaultRegRegion().write(reg_base + 0x03C, 1, true);   //配置1表示加法
104            //启动计算
105            device.defaultRegRegion().write(reg_base, 1, true); //启动寄存器
106            //轮询操作完成标志，done寄存器。只有等到done的时候才会跳出do while循环
107
108            //当一段时间等不到done之后，调用runtime的抛错接口，会抛出Timeout！！！
109            unsigned int reg_pre_done;
110            auto start = std::chrono::steady_clock::now();
111            do {
112                    reg_pre_done = device.defaultRegRegion().read(reg_base + 0x004, true);
113                    std::chrono::duration<double, std::milli> duration = std::chrono::steady_clock::now() - start;
114                    if (duration.count() > 1000) {
115                            throw std::runtime_error("Eltwise Timeout!!!");
116                    }
117            } while (reg_pre_done == 0);
118            device.defaultRegRegion().write(reg_base + 0x004, 1, true);  //清除done
119
120            //构造输出的tensor
121            auto ofm_dims = ofm_dtype->shape;
122            auto output_addr = backend->forward_info->value_map.at(op->outputs[0]->v_id)->phy_addr;   //byte地址  backend->forward_info->value_map.at(op->outputs[0]->v_id)->phy_addr;
123            auto output_info = backend->forward_info->value_map.at(op->outputs[0]->v_id);
124            auto mem_chunk = backend->phy_segment_map.at(output_info->segment)->memchunk;
125            auto output_tensor = icraft::xrt::Tensor(op->outputs[0].tensorType(), mem_chunk, output_info->phy_addr - mem_chunk->begin.addr());
126            std::vector<icraft::xrt::Tensor>output_tensors{ output_tensor };
127            return output_tensors;
128    };

18                            // 匹配add算子：IsOp<Add>
19                            // 匹配两输入的add算子：IsOp<Add>(Wildcard(), Wildcard())
20                            // 匹配其他限制条件：.setConstraint([](auto& op)
21                            auto add_p = IsOp<Add>(Wildcard(), Wildcard()).setConstraint([](auto& op) {
22                                    if (op->inputs[0].isParams() || op->inputs[1].isParams()) return false;
23                                    else if (op->inputs[0].tensorType()->shape == op->inputs[1].tensorType()->shape) return true;
24                                    else return false;
25                                    });
26
27                            auto results = network_.search(add_p);
28                            for (auto&& result : results) {
29                                    auto add = result.at(add_p).cast<Add>();
30                                    double a = add->alpha.cast<FloatImm>()->value;
31                                    double b = add->beta.cast<FloatImm>()->value;
32                                    auto eltwise = Eltwise(add->inputs[0], add->inputs[1], EltwiseMode::Add, a, b);
33                                    auto output_info = network_.getUsesInfo(add[0]);
34                                    network_.insertOpById(add->op_id, eltwise);
35                                    network_.removeOpById(add->op_id);
36                                    network_.connect(eltwise[0], output_info);
37                                    //先将算子加入网络，再修改CompileTarget
38                                    eltwise.setCompileTarget(FPGATarget::Init());
39                            }
40                            return network_;
41                    };
42                    Array<String> required_pass;
43                    return NetworkPass(pass_func, PassInfo("ReplaceAddWithEltwisePass", 1, required_pass));
44            }
45
46            ICRAFT_REGISTER_PASS("whatever.ReplaceAddWithEltwisePass").set_creator(ReplaceAddWithEltwisePass);
47    }

三 仿真对比#

为了验证自定义硬算子的正确性，将前后组件生成后的网络进行仿真对比结果。由于eltwise经过了量化，相比于浮点计算是有精度损失的，因此优化和量化阶段的余弦相似度，若其大于0.999则认为结果正确。其他阶段均没有损失。

 12    float CosineSimilarity(const float* v1, const float* v2, uint64_t size) {
 13            auto dotProduct = [](const float* v1, const float* v2, uint64_t size) {
 14                    float sum = 0.0;
 15                    for (uint64_t i = 0; i < size; ++i) {
 16                            sum += v1[i] * v2[i];
 17                    }
 18                    return sum;
 19            };
 20
 21            auto norm = [](const float* v, uint64_t size) {
 22                    float sum = 0.0;
 23                    for (uint64_t i = 0; i < size; i++) {
 24                            sum += v[i] * v[i];
 25                    }
 26                    return std::sqrt(sum);
 27            };
 28
 29            float dot = dotProduct(v1, v2, size);
 30            float normA = norm(v1, size);
 31            float normB = norm(v2, size);
 32
 33            if (normA == 0.0f || normB == 0.0f) {
 34                    throw std::invalid_argument("Norm should not be zero.");
 35            }
 36
 37            return dot / (normA * normB);
 38    }

 47    }
