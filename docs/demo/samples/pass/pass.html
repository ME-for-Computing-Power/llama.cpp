Icraft Demo: Pass#

在Icraft中，针对网络结构的增删查改或者对网络参数的重新赋值均可以通过XIR提供的接口来实现，每一个对网络的修改我们称之为一个Pass， 因此通过依次调用不同功能的Pass可以实现对网络的优化并最终转变为适配后端硬件的格式。

该Demo展示了如何定义Pass来实现对网络的转换，同时包含了如何通过配置文件将自定义的Pass嵌入Icraft的编译过程中以及如何通过API对Pass进行调用。 Demo中包含四个不同功能的Pass实现，下面将以 ConvertDivideScalar2MultiplyPass 为例来进行介绍。

一 工程配置#

1.1 文件结构#

samples/pass/ConvertDivideScalar2MultiplyPass
├───images
├───models
├───tests
├───ConvertDivideScalar2MultiplyPass.cpp

在上面的工程结构中：

  • images 存放的是用于量化的图片校准集

  • models 存放的是示例模型的相关文件：

    • divide_scalar.pt : Pytorch框架上导出的示例模型

    • divide_scalar.py : Pytorch框架上示例模型的源码

    • divide_scalar.toml : Icraft编译示例模型的配置文件

  • tests 存放的是测试的源文件test.cpp

  • ConvertDivideScalar2MultiplyPass.cpp 是将除法转换为乘法这个Pass的具体实现

1.2 编译生成#

以上工程文件属于 Icraft-Demo 工程的一部分，具体的编译生成方法请参考 Icraft-Demo 的编译生成的说明。

二 使用流程#

2.1 定义Pass#

2.1.1 Pass实现#

该Demo在 samples/pass/ConvertDivideScalar2MultiplyPass/ConvertDivideScalar2MultiplyPass.cpp 中完成了Pass的定义与注册， 该Pass的命名空间为 whatever，其生成的动态链接库的名字为 whatever.ConvertDivideScalar2MultiplyPass.dll。

备注

用户可以根据需要随意选择自定义Pass的命名空间和名称，但是需要保证编译的动态链接库的名称与toml文件中配置的相同，配置文件的介绍见下文。

假如我们现在想要实现一个将除法转换为乘法的功能Pass，那么具体的定义与注册方式如下所示：

 1namespace icraft::adapter {
 2    static Pass ConvertDivideScalar2MultiplyPass() { // 声明Pass
 3            auto pass_func = [](Network network_, const PassContext& pass_ctx) { // Pass的功能函数，包括传入的网络 Network，和表示Pass上下文的引用类 PassContext&
 4
 5                    auto divide_p = IsOp<DivideScalar>(Wildcard()); // 使用IsOp根据类型查找符合条件的算子，算子的输入使用 Wlidcard()通配符匹配任意输入
 6
 7                    network_.rewrite(divide_p, [&](Network& network, const MatchGroup& result) {    // 使用network_.rewrite()覆盖查找到的算子
 8                            auto divide = result.at(divide_p).cast<DivideScalar>();                                         // 使用at和cast方法将查找到的算子转成对应的类型
 9                            auto divisor = divide->divisor;                                                                                         // 获取divide算子的除数参数
10                            auto multi_data = 1 / divisor;                                                                                          // 根据算法原理构造乘法的乘数参数
11                            auto divide_shape = divide[0].tensorType()->shape;                                                      // 获取divide算子的输出特征图的形状
12                            auto channel = divide_shape.back();                                                                                     // 获取divide算子输出特征图的最后一维（通道维度）的大小
13                            auto weight_data = std::shared_ptr<float[]>(new float[channel]);                        // 构造乘算子的参数
14                            for (auto i = 0; i < channel; i++)
15                                    weight_data[i] = multi_data;
16
17                            Array<int64_t> weight_shape; // 构造乘算子的参数形状。
18                            for (auto j = 0; j < divide->inputs[0].tensorType()->shape.size(); j++) {
19                                    if (j == divide->inputs[0].tensorType()->shape.size() - 1) {
20                                            weight_shape.push_back(channel);
21                                    }
22                                    else {
23                                            weight_shape.push_back(1);
24                                    }
25                            }
26
27                            auto weights_layout = Layout("***C");                                                                                           // 构造乘算子的参数排布
28                            auto weights_type = TensorType(FloatType::FP32(), weight_shape, weights_layout);        // 构造乘算子的参数格式
29                            auto weights = Params(weights_type);
30                            weights.setData(weight_data);                                                                                                           // 给乘算子添加参数值
31
32                            auto multi_n = Multiply(divide->inputs[0], weights);    // 构造乘算子，其输入就是除算子的输入
33                            network_.insertOpById(divide->op_id, multi_n);                  // 使用insertOpById方法将构造的乘算子添加至除算子之前
34                            auto divide_info = network_.getUsesInfo(divide[0]);             // 使用getUsesInfo方法获取并保存除算子在网络内的连接关系
35                            network_.removeOpById(divide->op_id);                                   // 使用removeOpById方法将除算子从网络内移除
36                            network_.connect(multi_n[0], divide_info);                              // 使用connect方法将新添加的乘算子与除算子的连接关系相连
37                    });
38                    return network_; // 返回修改后的网络
39            };
40            Array<String> required_pass;
41            return NetworkPass(pass_func, PassInfo("ConvertDivideScalar2MultiplyPass", 1, required_pass)); // 返回Pass
42    }
43    ICRAFT_REGISTER_PASS("whatever.ConvertDivideScalar2MultiplyPass").set_creator(ConvertDivideScalar2MultiplyPass); //在Icraft内注册Pass
44}

2.1.2 编译链接#

Pass的定义完成后，我们需要将源码编译链接为动态链接库，相应的CMake脚本如下：

 1# 根据上文中所述命名规则，创建动态链接库
 2add_library(whatever.ConvertDivideScalar2MultiplyPass SHARED "")
 3
 4# 添加源文件
 5target_sources(whatever.ConvertDivideScalar2MultiplyPass PRIVATE
 6    ConvertDivideScalar2MultiplyPass.cpp
 7)
 8
 9# 由于源文件中使用了XIR的接口，需要链接相应的库
10target_link_libraries(whatever.ConvertDivideScalar2MultiplyPass PUBLIC Icraft::XIR)

以上脚本在Windows下编译生成 whatever.ConvertDivideScalar2MultiplyPass 文件

2.2 调用Pass#

2.2.1 通过Icraft调用#

运行Icraft之前需要让Icraft能够找到以上生成的 whatever.ConvertDivideScalar2MultiplyPass.dll，可通过以下方式实现：

  • 【不推荐】将以上生成的动态链接库复制到 C:\Icraft\CustomOp_v3.0.0 文件夹下

  • 【☆推荐】设置环境变量 ICRAFT_CUSTOM_DIR ，指向以上动态链接库所在的文件夹。比如在Windows下，可以使用PowerShell命令 $env:ICRAFT_CUSTOM_DIR="path/to/dll/dir" 来实现,如果用户网络还需要用到Icraft提供的customop，可以使用命令 $env:ICRAFT_CUSTOM_DIR="path/to/dll/dir;C:\Icraft\CustomOp_v3.0.0" 将Icraft Customop的路径一并配置到 ICRAFT_CUSTOM_DIR。

为了能在Icraft编译过程中调用该Pass，可以在optimize或adapt这两个section中通过 pass_on 参数配置Pass的名称从而实现自动调用。

备注

目前仅支持在optimize和adapt这两个section中配置pass_on

各个编译过程的配置如下：

 1[parse]
 2net_name = "divide_scalar"
 3framework = "pytorch"
 4frame_version = "1.9"
 5inputs = [ 1, 32, 32, 3]
 6inputs_layout = "NHWC"
 7pre_scale = [ 1, 1, 1]
 8pre_mean = [ 0, 0, 0]
 9pre_method = "resize"
10channel_swap = [ 0, 1, 2]
11network = "../../samples/pass/ConvertDivideScalar2MultiplyPass/model/divide_scalar.pt"
12jr_path = "./json&raw/"
13
14[optimize]
15target = "BUYI"
16json = "./json&raw/divide_scalar_parsed.json"
17raw = "./json&raw/divide_scalar_parsed.raw"
18jr_path = "./json&raw/"
19pass_on = "whatever.ConvertDivideScalar2MultiplyPass"
20
21[quantize]
22forward_mode = "image"
23saturation = "kld"
24forward_dir = "../../samples/pass/ConvertDivideScalar2MultiplyPass/images/"
25forward_list = "../../samples/pass/ConvertDivideScalar2MultiplyPass/images/pic_list.txt"
26bits = 8
27json = "./json&raw/divide_scalar_optimized.json"
28raw = "./json&raw/divide_scalar_optimized.raw"
29jr_path = "./json&raw/"
30per = "tensor"
31target = "buyi"
32
33[adapt]
34target = "BUYI"
35json = "./json&raw/divide_scalar_quantized.json"
36raw = "./json&raw/divide_scalar_quantized.raw"
37jr_path = "./json&raw/"
38
39[generate]
40json = "./json&raw/divide_scalar_adapted.json"

编译的命令如下：

# 进入build文件夹，避免生成的文件污染源目录
cd build/windows-x64-release
icraft compile ..\..\samples\pass\ConvertDivideScalar2MultiplyPass\model\divide_scalar.toml

2.2.2 通过API调用#

除了通过Icraft在编译过程中调用该Pass外，还可以灵活地通过Icraft提供的C++ API进行调用。

备注

当前的API必须提供 Pass.dll 所在的路径才能完成调用，因此建议将 Pass.dll 置于 ICRAFT_CUSTOM_DIR 所指向的路径下。

 1// 加载网络
 2    auto network = Network::CreateFromJsonFile(json_file);
 3    network.loadParamsFromFile(raw_file);
 4    auto output = Sim(network, input_tensor);
 5
 6    //获取ICRAFT_CUSTOM_DIR所指向的路径并调用该路径下的Pass
 7    std::string custom_dirs_env = getenv("ICRAFT_CUSTOM_DIR");
 8    std::string dll_path = custom_dirs_env + "/" + pass_name + ".dll";
 9    auto execute = Pass::Create(pass_name, dll_path);
10    auto network_passed = execute(network);

三 仿真对比#

为了验证Pass功能的正确性，我们对经过Pass处理的网络和未经Pass处理的网络进行仿真对比结果。 由于某些Pass的变换是有数值差异的，因此我们计算两个阶段网络仿真结果的余弦相似度，并分别针对不同Pass设置不同的阈值。

该Demo在 samples/pass/ConvertDivideScalar2MultiplyPass/tests/test.cpp 中完成了结果验证，主要实现如下：

 1try {
 2            std::string JSON_FILE = "json&raw/divide_scalar_parsed.json";
 3            std::string RAW_FILE = "json&raw/divide_scalar_parsed.raw";
 4            std::string PASS_NAME = "whatever.ConvertDivideScalar2MultiplyPass";
 5            testPass(JSON_FILE, RAW_FILE, PASS_NAME);
 6
 7            std::string JSON_FILE_PASSED = "json&raw/divide_scalar_optimized.json";
 8            std::string RAW_FILE_PASSED = "json&raw/divide_scalar_optimized.raw";
 9            testCompile(JSON_FILE, RAW_FILE, JSON_FILE_PASSED, RAW_FILE_PASSED);
10    }
11    catch (std::exception& e) {
12            std::cout << e.what() << std::endl;
13    }

其中 testCompile 是对前述icraft compile生成的模型进行仿真对比， testPass 是通过Icraft的C++ API再次调用Pass完成网络的转换，并计算两个阶段的余弦相似度， 两个测试共同保证通过Icraft编译调用和通过API调用该Pass的功能均正确。

该Demo在 samples/pass/ConvertDivideScalar2MultiplyPass/tests/test.py 中调用Icraft的Python API完成了结果验证，主要实现如下：

1JSON_FILE = r"json&raw/divide_scalar_parsed.json"
2RAW_FILE = r"json&raw/divide_scalar_parsed.raw"
3PASS_NAME = "whatever.ConvertDivideScalar2MultiplyPass"
4TestPass(JSON_FILE, RAW_FILE, PASS_NAME)
5
6JSON_FILE_PASSED = "json&raw/divide_scalar_optimized.json"
7RAW_FILE_PASSED = "json&raw/divide_scalar_optimized.raw"
8TestCompile(JSON_FILE, RAW_FILE, JSON_FILE_PASSED, RAW_FILE_PASSED)
