Icraft XRT: snapshot#

这个用例共提供两个demo，分别用于说明如何生成以及使用快照文件。

一 工程配置#

1.1 demo结构#

samples/xrt/snapshot
├───serialize.cpp
└───deserialize.cpp

在上面的工程结构中：

  • serialize 是序列化session生成快照文件的demo，包含c++和python工程

  • deserialize 是由快照文件反序列化得到session的demo，包含c++和python工程

1.2 编译生成#

以上工程文件属于 Icraft-Demo 工程的一部分，具体的编译生成方法请参考 Icraft-Demo 的编译生成的说明。

二 Demo说明#

2.1 serialize demo#

目前序列化session仅支持BY阶段的网络，在device、backend的各项配置请在序列化前进行调用。 主要实现如下，需注意序列化接口调用时机，在完成session部署后调用：

//根据序列化的网络json文件反序列化成icraft::xir::network对象
auto network = Network::CreateFromJsonFile(json_file);
//network加载raw_file
network.lazyLoadParamsFromFile(raw_file);
//创建session，将buyibackend以及hostbackend绑定到sess对象上
auto sess = icraft::xrt::Session::Create<BuyiBackend, HostBackend>(network, { device, HostDevice::Default() });
//session执行前必须进行apply部署操作
sess.apply();
//序列化sess生成快照文件，并保存快照文件至指定路径
sess.dumpSnapshot(snapshot_file);

network = Network.CreateFromJsonFile(json_file)
network.lazyLoadParamsFromFile(raw_file)

sess = Session.Create([ BuyiBackend, HostBackend ], network.view(0), [device, HostDevice.Default()])
sess.apply()

#序列化sess生成快照文件
sess.dumpSnapshot(snapshot_file)

2.2 deserialize demo#

该demo实现由快照文件反序列化得到session，具体包含了构造网络network和apply部署，构建得到session后直接进行前向。 其中对mmu模式、合并算子和内存优化等配置无效，而是与生成快照文件时的配置一致。 主要实现如下：

//由快照文件构建session，并完成apply部署
Session sess = Session::CreateWithSnapshot(snapshot_file, { BuyiBackend::Init(), HostBackend::Init() }, { device, HostDevice::Default() });

//借助HostBackend的工具函数将输入图片转成Tensor
auto input_tensor = icraft::hostbackend::utils::Image2Tensor(img_file);
//前向
auto outputs = sess.forward({ input_tensor });

sess = Session.CreateWithSnapshot(snapshot_file,[ BuyiBackend, HostBackend ],[device, HostDevice.Default()])

# 调用HostBackend的辅助函数将图片转为Tensor
input_tensor = Image2Tensor(img_file, -1, -1)
# 前向，获取输出
output_tensors = sess.forward([ input_tensor ])
