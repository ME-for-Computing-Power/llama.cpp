Icraft Demo#

Icraft Demo为一系列工程示例的集合，用于演示Icraft v3的使用方法。

编译生成说明#

准备工作#

  • 【☆必须】Iraft Demo的编译链接依赖了较多Icrat库文件，因此请先安装Icraft V3.0，又因为Demo中包含了c++和python两种版本的测试程序，请安装 Icraft Setup.exe 的同时，一并安装``icraft-3.0.0-cp38-none-win_amd64.whl``。

  • 【非必须】如需跑自定义算子相关的demo，因为自定义算子需要实现自定义解析，因此需要额外安装依赖。Pytorch框架 模型，需要安装 pytorch2.0.1 ；Onnx框架 模型，需要编译安装 ptorobuf3.21。

  • 【非必须】如需跑前向相关的demo，因为demo包含后处理运算，需要编译OpenCV。编译方式参见《xrt运行相关用例/yolov5s运行/环境配置》

编译生成#

当获取工程源码后，按照如下步骤操作：

  • 用 Visial Stidio 打开工程文件；

  • 在 解决方案资源管理器 中找到Icraft-Demo 最外层的CMakeLists.txt ，右键点击 生成，即可实现工程的构建和编译。

调试和运行#

Icraft Demo为每个示例提供了单独的说明文档，参照具体的demo说明文档即可实现示例的调试和运行。
