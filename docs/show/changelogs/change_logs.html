更新日志#

v3.7.0#

  • Feature 新增

    • 新增：使用C++ CROW框架重构后端

    • 新增：log_path参数设置保存文件的路径，详见 命令行参数列表

    • 新增：支持了win7系统的使用

  • Bug 修复

    • 修复：修复量化分析工具平均值选项

    • 修复：修复网络太深时导致的堆栈溢出问题

v3.6.0#

  • Feature 新增

    • 新增：设置网络可视化标题框为可拖动

    • 新增：量化分析支持了其他阶段的网络输入

    • 新增：量化分析采样图表新增了步长、起始点选项

    • 新增：支持通过参数直接对比 dump 的两个文件夹，详见 命令行参数列表

v3.5.0#

  • Bug 修复

    • 修复：内存优化分析输入为null时的bug

    • 修复：快捷菜单打开imodel时不能显示weights的bug

v3.4.0#

  • Feature 新增

    • 新增：内存优化分析功能，详见 内存优化分析

    • 新增：量化分析添加fake_qf功能以检查溢出问题 fake_qf

  • Bug 修复

    • 修复：卸载时残留文件bug

    • 修复：windows下量化分析路径带空格的bug

v3.3.0#

  • Feature 新增

    • 新增：windows下快捷菜单功能

  • 性能 优化

    • 优化量化分析输入图片逻辑，详见 量化分析输入

  • Bug 修复

    • 修复：指令传递时int64的精度问题

    • 修复：bn、ln和InstanceNorm2d算子无法显示参数的bug

v3.2.0#

  • Bug 修复

    • 修复：量化分析工具图表ftmp_id显示错误的bug
