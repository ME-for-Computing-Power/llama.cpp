【发布时间】 2024.12.24

    • Parser组件：OnnxParser修复反卷积算子layout指定错误的bug，该bug的修复解决了反卷积算子的量化精度问题，影响网络：YoloV6s_v2_reopt和simple_pose；

    • Quantizer组件：修复了matmul_const量化优化环节引入的截位相关的bug，影响网络：EcapaTDNN；

    • CodeGen组件：修复算子中无效通道大于cu的情况中bug，影响网络：pointnet和yolov8_cls混合精度模式；

    • Show组件：修复了log_path指定错误的bug；

    • Show组件：修复量化分析工具分析多输入网络时，报Internal Server Error的bug，影响网络：EcapaTDNN；

    • Show组件：修复命令行打开show中存在的权限问题；

    • Show组件：修复show工具多次打开时，从第二次开始无法启动的bug；

v3.7.0#

【发布时间】 2024.11.29

【版本说明】

  1. 调整支持的深度学习框架

    • Darknet：不再支持Darknet框架网络的编译部署；

    • Tensorflow：增加TensorFlow2Onnx的模型，支持tf1、tf2保存的Onnx模型，详见 《Icraft Docs之算子支持》；

  2. 调整算子库

    Pytorch（仅限pytorch转onnx），详见 《Icraft Docs之算子支持》：

    • AdaptiveAvgPool3d（算子约束，详见 《Icraft Docs之算子支持》）

    • AdaptiveMaxPool3d

    • AvgPool3d（算子约束，详见 《Icraft Docs之算子支持》）

    • BatchNorm3d

    • Conv3d

    • MaxPool3d

    • InstanceNorm3d

    • equal

    • greater

    • greater_equal

    • less

    • less_equal

    • mean（完善算子支持程度，完全支持）

    • not_equal

    PaddlePaddle（仅限paddlepaddle转onnx），详见 《Icraft Docs之算子支持》：

    • AdaptiveAvgPool3d（算子约束，详见 《Icraft Docs之算子支持》）

    • AdaptiveMaxPool3d

    • AvgPool3d（算子约束，详见 《Icraft Docs之算子支持》）

    • BatchNorm3d

    • Conv3d

    • MaxPool3d

    • equal

    • greater_equal

    • greater_than

    • InstanceNorm3d

    • less_equal

    • less_than

    • MaxPool3d

    • mean（完善算子支持程度，完全支持）

    • not_equal

  3. 新增和升级功能

    • Xir组件：新增一种序列化和反序列化方式——flatbuffers （只支持对 Network 序列化和反序列化），详见 《Icraft Docs之Xir用户手册》

    • Xir组件：模式匹配新增 IsOptionalOp ，可用于添加不确定是否存在的 OpPattern；

    • Xir组件：优化json 反序列化时的内存占用和耗时（反序列化速度提升5倍）；

    • Xir组件：支持算子有多个相同的输入，例如concat的所有或部分输入为同一个ftmp；

    • Xir组件：序列化接口函数升级，新增参数 validate ，决定序列化时是否检查网络必须符合规范，默认开启，便于网络调试；

    • Parser组件： OnnxParser支持unsupport算子，对于不支持算子解析为unsupport算子占位并保存josn&raw文件，方便查看、分析网络;

    • Parser组件： OnnxParser新增支持TensorFlow2Onnx的模型，支持tf1、tf2保存的Onnx模型，仅支持data_format为默认值channels_last，即排布为NHWC格式，详见 《Icraft Docs之算子支持》；

    • Adapter组件：优化reshape_layout，优化后不改变通道的reshape将不再返回框架排布，有效的减少transpose的引入，提升网络性能；该方案改变了reshape的处理方式，少量特定结构会产生额外的开销，针对该场景可以考虑定制pass的优化方案，例如我们针对yolov5_transfomer添加了定制的pass来解决性能变差的问题；

    • Quantizer组件：优化matmul量化方案，当其中一个输入为相同值的常数，将常数量化至定点数1，尽可能减少ftmp过大时乘累加的溢出；

    • HostBackend组件：Ftmp2Tensor添加了文件大小检查，如果文件大小和Tensor大小不匹配报warning；

    • Xrt组件：优化OpenDevice 时间，优化后基本与Icraft 2.x的时间一致；

    • Icraft-Show组件：支持在win7下应用；

    • Icraft-Show组件：log_path参数设置保存文件的路径，详见 《Icraft Docs之Icraft-Show用户手册》

  4. 修复Bug

    • OnnxParser：修复Gather算子indices为负数解析错误的bug，影响网络：maskformer_R50_640x640；

    • OnnxParser：修复Squeeze算子axis为空时不支持解析的bug，影响网络：trajairnet；

    • Quantizer：修复通过ftmp_csv手动配置Cast算子的量化系数时系数传递错误的bug，影响网络：isegpost；

    • CodeGen：修复网络中存在的负数v_id的bug；

    • CodeGen：修复16bit下pad刷常数时未刷满整个输出范围及pad_value的值错误的bug；

    • CodeGen：绕开olm硬件的bug，对rolm与wolm的地址进行偏移（常在expand算子遇到）；

    • Icraft-Show：修复量化分析工具平均值选项；

    • Icraft-Show：修复网络太深时导致的堆栈溢出问题，影响网络：CAMpplus；

v3.6.2#

【发布时间】 2024.09.12

【版本说明】

  1. 调整算子库

    pytorch，详见 《Icraft Docs之算子支持》：

    • sum

    • sqrt

    • clamp

  2. 新增功能

    • Parser组件：根据Icraft硬件特性，升级parser对1D算子的解析方式，从而提升1D算子的性能。影响网络：swin_tiny_patch4_window7_224.pt；

    • Parser组件：全面升级OnnxParser，OnnxParser目前支持Pytorch（opset17）、PaddlePaddle（opset11），详见 《Icraft Docs之算子支持》；

    • Parser组件：升级预检功能，新增参数pre_check，默认为true，用于启动整个编译器级别的模型预检；配置为false，则只完成Parser组件的预检。也就是说，用户调试网络时可以配置pre_check=false，将网络尽量向前编译。目前仅OnnxParser支持支持升级后的模型预检功能，详见《Icraft Docs之解析用户手册》第一节： “CLI说明” ；

    • Adapter组件：针对BuyiLayoutPass中适配通道添加出的conv2d进行优化，提升网络性能；

    • Icraft Show组件：新增了任意两阶段的网络误差分析功能；新增命令行参数对比两个文件夹下的ftmp的功能，且ftmp的采样支持配置步长、起始点用于选择采样范围，详见 《Icraft Docs之Icraft-Show用户手册》。

  3. 功能升级

    • custom_op：detpost position参数配置-1表示筛选全部。影响网络：使用detpost且筛选位置为all的检测模型；

    • custom_op：detpost config_id参数由配置实际ftmp调整为配置第几个输出，默认从0开始。影响网络：yolov5_seg、yolov8_seg、yolov9_pan；

    • custom_op：segpost 支持多输出网络指定输出进行筛选。影响网络：DDRNet；

  4. 修复Bug

    • 快照：解决不支持内存复用的bug；

    • BuyiBackend组件：解决multiply算子改指令函数中的某个判断分支有误的bug；

    • Quantizer组件：解决split算子normratio中的bug。影响网络：shufflenet；

    • CodeGen组件：解决构造包含无效通道的查找表（例如激活函数）时的bug；

    • CodeGen组件：解决合并算子后ftmp顺序可能发生变化的bug。影响网络：yolov9c；

    • CodeGen组件：解决prune和align算子分配地址使用了ocm的bug。影响网络：aiatrack；

    • CodeGen组件：解决部分模式匹配次数上限配置不合理的bug。影响网络：lstm；

    • Xir组件：解决ConnetInput没办法正确插入Input的bug。影响网络：yolov7；

    • Xir组件：解决网络中param.v_id与value.v_id分配不同步导致网络外面游离value的v_id与网络中param.v_id冲突的bug。

    • PytorchParser组件：解决slice算子不支持参数为负数的bug。影响网络：lstm;

  3. Icraft中间层进行了升级，优化数据结构，提供模式匹配功能，优化支持针对网络的增删查改，优化算子注册流程。相关介绍详见《Icraft Docs之Icraft组件总览——XIR用户手册》

  4. Icraft前向进行了统一，所有前向统一接口为XRT，不再区分仿真和运行，而是把不同的计算资源抽象为不同的后端，使得Icraft中的网络能够在任意的计算资源上完成计算。相关介绍详见《Icraft Docs之Icraft组件总览——XRT用户手册》

  5. 优化自定义算子接口。相关介绍详见《Icraft Docs之自定义算子》

  6. 提供可视化分析工具Icraft-show，终端命令行启动为icraft show，即可启动该工具。相关介绍详见《Icraft Docs之Icraft组件总览——Icraft-Show用户手册》
