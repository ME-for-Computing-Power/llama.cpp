更新日志#

v3.7.0#

  • 性能 优化

    • 新增 icraft.SplitCompareSeqPass,支持等于，小于，大于，不等于，小于等于，大于等于算子。详见 Icraft Adapter内置Pass列表

    • 新增 icraft.SplitConv3DSeqPass, icraft.ConvertNorm3d2Norm2dPass,支持3D卷积, 3D Norm算子，以及合并3D卷积和3D BatchNorm。详见 Icraft Adapter内置Pass列表

    • 新增 icraft.ConvertPool3d2Pool2dPass, icraft.ConvertPad3d2Pad2dPass,支持3D Pool, 3D Pad, 3D BatchNorm, 3D InstanceNorm算子。详见 Icraft Adapter内置Pass列表

    • 新增 icraft.ConvertMean2AvgpoolPass,用于优化mean算子的执行方式，提升性能。详见 Icraft Adapter内置Pass列表

    • 新增 icraft.DeepOptimizeTransDataSeqPass,用于在量化之前优化transpose和reshape算子，删除无用的transpose和reshape算子。详见 Icraft Adapter内置Pass列表

    • 新增 icraft.yolotransfomer_MergeMatmulDimPass,用于优化yolotransformer网络内的matmul，提升matmul的计算效率。详见 Icraft Adapter内置Pass列表

    • 修改 icraft.BuyiLayoutSeqPass,修改reshape算子layout，优化reshape算子在不对C和c做修改时的执行效率。

v3.6.0#

  • 性能 优化

    • 新增 icraft.PostProcessSpecialConv2dPass，用于优化adapter适配过程中添加的conv2d算子，减小网络计算量，提升性能。详见 Icraft Adapter内置Pass列表

v3.5.0#

  • Bug 修复

    • 修复：copyFtmpPass在特定结构出错的bug

v3.4.0#

  • 性能 优化

    • 新增 icraft.InputfoldPass ，用于折叠网络的常量输入，减小网络计算量，提升性能。详见 Icraft Adapter内置Pass列表

v3.3.0#

  • 性能 优化

    • 优化 PixelShuffle 算子的下降方式，提升网络性能

v3.2.0#

  • Bug 修复

    • 修复：concat_layout中的bug
